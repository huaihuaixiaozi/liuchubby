# liuchubby

Home of [`agent-skills-dsh`](./agent-skills-dsh) — a DeepSeek Harness plugin
shipping 24 engineering workflow skills, 4 review personas, and 8 lifecycle
slash commands.

The package lives in [`agent-skills-dsh/`](./agent-skills-dsh), not at the
repository root, so the install spec carries the subdirectory.

## Install

```sh
dsh plugin --profile web add github:huaihuaixiaozi/liuchubby#path:/agent-skills-dsh
```

Then restart the web profile. See
[`agent-skills-dsh/README.md`](./agent-skills-dsh/README.md) for the skill and
command tables, and [`agent-skills-dsh/RELEASE.md`](./agent-skills-dsh/RELEASE.md)
for the market-listing values.
